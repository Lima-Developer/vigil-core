# Vigil Core

-----

Sistema OpenSource para observabilidade e curadoria de consultas SQL em bancos PostgreSQL
## Demonstração de um caso

A aplicação local permite criar um caso, inspecionar métricas e plano identificados como dados de laboratório, e registrar uma triagem auditável no SQLite. Consulte [o roteiro de execução](docs/bootstrap/caso-demonstracao.md) para iniciar o JAR e repetir o fluxo da apresentação.
